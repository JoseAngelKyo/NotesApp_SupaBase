# 📝 NotesApp con Supabase

⭐ **5to Semestre - UPC | Julio 2026**

Esta aplicación web interactiva, basada en un Dashboard moderno, es un proyecto práctico desarrollado para gestionar notas y recuerdos en tiempo real. Su objetivo principal es permitir la creación, visualización y eliminación de notas dinámicas, organizándolas automáticamente mediante categorización visual por colores e íconos, garantizando la persistencia de datos en la nube y la protección de credenciales sensibles.

---

## 🛠️ Herramientas y Tecnologías

* **Frontend:** HTML5, CSS3 (CSS Grid & Flexbox), JavaScript (`Async/Await`).
* **Base de Datos & Backend:** Supabase (PostgreSQL), Row Level Security (`RLS`).
* **Librerías & Iconos:** FontAwesome v6, Google Fonts (`Plus Jakarta Sans`).
* **Control de Versiones & Seguridad:** Git, GitHub, `.gitignore` (Variables de entorno).
